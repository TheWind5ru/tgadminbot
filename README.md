# 🛡️ Telegram Group Moderator Bot

Профессиональный бот для модерации Telegram-групп на базе библиотеки **pyTelegramBotAPI**. Предназначен для автоматического контроля порядка, управления правами пользователей и автоматической блокировки чата в ночное время.

## ✨ Основные функции

* **🧱 Ночной режим (Night Mode):** Автоматическая блокировка возможности отправки сообщений для всех участников с **17:00 до 06:00** по московскому времени.
* **🔗 Анти-спам ссылок:** Блокировка любых внешних ссылок, кроме разрешенного "белого списка" (White-list).
* **⚠️ Система предупреждений (Warns):** Автоматический мут пользователя на 1 час при достижении 3-х предупреждений.
* **🔇 Управление ограничениями:** Команды для ручного бана, кика и мута (с указанием времени).
* **📂 Логирование действий:** Все наказания (баны, кики, муты, варны) сохраняются в локальную базу данных JSON.
* **🚫 Запрет сообщений от каналов:** Автоматическое удаление сообщений, отправленных от имени анонимных каналов.

## 🛠 Технологический стек

* **Язык:** Python 3.x
* **Библиотека бота:** `pyTelegramBotAPI` (Telebot)
* **База данных:** `TinyDB` (легковесная NoSQL БД в формате JSON)
* **Работа со временем:** `pytz` (учет часовых поясов)
* **Окружение:** `python-dotenv`

## 🚀 Быстрый старт

### 1. Подготовка

Склонируйте репозиторий:

```bash
git clone https://github.com/vash-logic/telegram-moderator-bot.git
cd telegram-moderator-bot

```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt

```

*(Создайте файл `requirements.txt` и добавьте туда: `pyTelegramBotAPI`, `tinydb`, `pytz`, `python-dotenv`)*

### 3. Настройка переменных окружения

Создайте файл `.env` в корневой папке проекта:

```env
BOT_TOKEN=ваш_токен_бота
ADMINS=id_админа1,id_админа2

```

### 4. Запуск

```bash
python main.py

```

## 📝 Команды администратора

| Команда | Описание |
| --- | --- |
| `/ban` | Забанить пользователя (ответ на сообщение) |
| `/unban` | Разбанить пользователя |
| `/kick` | Кикнуть пользователя из чата |
| `/mute [мин]` | Замутить на X минут (по умолчанию 60) |
| `/unmute` | Снять все ограничения |
| `/warn` / `/unwarn` | Выдать/снять предупреждение |
| `/warnlist` | Посмотреть список всех нарушителей |
| `/mutelist` | Список текущих мутов |

## ⚙️ Логика работы планировщика

Бот использует фоновый поток (`threading`), который каждую минуту проверяет:

1. **Текущее время в МСК:** Если наступило время блокировки, бот закрывает чат и отправляет уведомление.
2. **Истекшие муты:** Бот автоматически проверяет базу данных и возвращает права пользователям, чей срок мута подошел к концу.
